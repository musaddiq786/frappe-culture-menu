# 🍽️ Frappe Culture Menu

A simple practice project built using the Frappe Framework to explore how cultural or regional menu-based applications can be designed and managed.

---

## 🌐 Live Demo

🔗 https://frappe-culture.lovable.app

---

## 🚀 About the Project

Frappe Culture Menu is a beginner-level project created while learning the Frappe Framework.  
It demonstrates how to build a basic full-stack application using Frappe’s built-in tools.

This project focuses on:
- Understanding Frappe app structure  
- Working with DocTypes (data models)  
- Handling backend logic using Python  
- Creating simple UI components  

---

## 🛠️ Tech Stack

- Frappe Framework (Python + JavaScript)  
- MariaDB (default database used by Frappe)  
- HTML / CSS  

---

## ✨ Features

- Basic menu-based structure  
- Data handling using Frappe DocTypes  
- Simple UI rendering  
- Backend logic with Python

## ⚙️ Installation (For Learning Purpose)

Make sure you have Frappe Framework installed.

```bash
# Clone the repository
git clone https://github.com/musaddiq786/frappe-culture-menu.git

# Navigate into the project
cd frappe-culture-menu

# Get the app in your bench
bench get-app frappe_culture_menu .

# Install the app on your site
bench --site your-site-name install-app frappe_culture_menu

# Start the development server
bench start
